# Backend — задание 1. Основы Python

Консольная программа для записи клиента в салон. Python-заготовки в репозитории не было, поэтому пример сделан отдельно от frontend-практик. Используются только модули стандартной библиотеки, установка пакетов не нужна.

## Что сделано

1. Вместо словаря функция `create_appointment()` возвращает объект класса `Appoinment`. Название класса сохранено как в условии. Поля: `id`, `client_name`, `master_id`, `service_id`, `time`.
2. Запись создаётся только при заполненных имени, мастере, услуге и времени. Мастер и услуга должны существовать. Пустые строки и строки из пробелов не принимаются.
3. Время проверяется в формате `ЧЧ:ММ`. Разрешён интервал с **08:00 до 20:00 включительно**. Длительность услуг в условии не задана, поэтому проверяется время начала записи.
4. При неверных данных возвращается `None`, а список `appointments` не изменяется.
5. Сохранено упомянутое в тексте исходное ограничение: одно время нельзя занять повторно, в том числе у другого мастера. Новое бизнес-правило этой практики — проверка часов работы.

## Запуск

Нужен Python 3.10 или новее. Из корня репозитория:

```sh
cd backend-1-practice
python main.py
```

В Windows вместо `python` можно использовать `py -3`, если установлен Python Launcher.

Результат:

```text
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00
Запись без имени: None
Запись на 00:00: None
Количество записей: 2
```

В `main.py` есть минимальные справочники: мастера с ID 1 и 2, услуга с ID 1. Это позволяет запустить приведённые в задании примеры без других файлов и сервера. Данные хранятся в памяти до завершения программы.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверяются две корректные записи, незаполненные поля, неизвестные ID, формат времени, границы 08:00/20:00, время вне рабочего интервала, занятое время и сохранность существующих записей после отклонённой попытки.

## Опечатки в условии

`len(appointments)` возвращает число: `0` для пустого списка, `2` после двух успешных записей. Чтобы вывести сам пустой список `[]`, нужно написать `print(appointments)`. Некорректная попытка не удаляет уже созданные записи. `len(appointment)` также не подходит: `appointment` — одна запись, а не список.
