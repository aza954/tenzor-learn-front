# Задание 4. Асинхронный JavaScript — НЕБО

Страница «Выбор даты и времени» из задания 3 с имитационным сервером. Оформление и компоненты сохранены. Дата «сегодня» и слоты загружаются через `fetch`, данные находятся только на сервере.

## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm.

```sh
cd frontend-4-practice
npm install
npm run dev
```

Откройте адрес из терминала, по умолчанию `http://localhost:3000`. Если порт занят, Vite укажет другой. Отдельно запускать сервер не нужно — он подключён как плагин Vite.

```sh
npm run build
npm run preview
```

В режиме preview имитационный API тоже работает. На обычном статическом хостинге для API потребуется отдельный сервер.

## Структура

- `server/database.js` — серверная дата и два набора слотов `{ time, available }`. Для соседних дней используются разные наборы.
- `server/server.js` — плагин Vite, перехватывающий `/api/*`. `DELAY_MS = 700` имитирует задержку сети.
- `src/api.js` — `fetchToday()` и `fetchSlots(date)`, проверка `response.ok` и формата JSON.
- `src/App.jsx` — отдельные состояния данных, загрузки и ошибки для каждого запроса. `useEffect` загружает дату при открытии, а слоты — при выборе дня.
- `src/components/` — компоненты страницы из задания 3; календарь получает «сегодня» через props, слоты показывают загрузку или ошибку.
- `src/data/date.js` — чистые функции для календаря и форматирования дат.

## API

Месяц нумеруется с нуля: 0 — январь, 9 — октябрь.

- `GET /api/booking/today` → `{ "day": 15, "month": 9, "year": 2026 }` (значение задаётся в `database.js`).
- `GET /api/slots?day=17&month=9&year=2026` → `{ "date": { "day": 17, "month": 9, "year": 2026 }, "slots": [{ "time": "10:00", "available": false }, ...] }`.

Некорректные даты дают HTTP 400, неизвестные эндпоинты — 404, неподдерживаемый метод — 405, ошибка обработки — 500. Все ответы API — JSON.

## Что проверить

1. При открытии видно «Загрузка…», затем появляется календарь на месяц серверной даты. Сегодня выделено, прошедшие дни отключены. После «Загрузка слотов…» появляются интервалы.
2. При выборе другого дня старое время сбрасывается, старые слоты скрываются, показывается загрузка. Выбранное свободное время появляется в нижней панели с полной датой. При быстрой смене дней отменённые ответы не меняют текущие слоты: используются `AbortController`, флаг актуальности эффекта и сравнение `date` из ответа.
3. Для проверки ошибки откройте DevTools → Network request blocking и заблокируйте `*/api/slots*`, затем выберите другой день. Появится сообщение об ошибке и кнопка «Повторить». Отключите блокировку и нажмите её. Аналогично можно проверить загрузку даты, заблокировав `*/api/booking/today*` и обновив страницу.

HTTP 500 также обрабатывается как ошибка с сообщением; бесконечной загрузки нет. Пустой ответ слотов показывает «На эту дату свободного времени нет». Кнопка «Далее», как в предыдущей практике, показывает выбранные данные в диалоге.
