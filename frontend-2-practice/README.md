# Задание 2. JavaScript — НЕБО

Страница выбора даты и времени на нативном JavaScript. Вёрстка перенесена из `frontend-1-practice`.

## Запуск

Откройте `index.html` в браузере или через Live Server в VSCode. Сборка и установка зависимостей не нужны.

## Файлы

- `index.html` — разметка; `script.js` подключён внизу `body`.
- `styles.css` — оформление и адаптация для телефонов.
- `script.js` — данные, состояние, чистые функции, рендер, обработчики и `init()`.
- `images/` — папка для изображений, если понадобятся.

## Что работает

- При открытии выбран сегодняшний день из `new Date()`, сразу показаны его слоты.
- Календарь строится по месяцам, недели начинаются с понедельника. Стрелки переключают месяц, включая переход между годами.
- Прошедшие дни приглушены и отключены.
- Выбор дня обновляет учебные слоты и сбрасывает выбранное время.
- Занятые слоты недоступны. Выбранное свободное время отображается в нижней панели вместе с полной датой.
- «Далее» доступна после выбора времени и показывает выбранные данные в диалоге. Остальных страниц записи в исходном макете нет.

Слоты — демонстрационные данные, вычисляемые для каждой даты. Подключения к серверу нет.
