# Задание 3. Основы React — НЕБО

Страница выбора даты и времени из `frontend-2-practice`, переписанная на React и Vite. Оформление, пять шагов записи и учебные данные слотов сохранены.

## Запуск

Нужны Node.js 20.19+ или 22.12+ и npm ([требования Vite](https://vite.dev/guide/)).

В терминале из корня репозитория:

```sh
cd frontend-3-practice
npm install
npm run dev
```

Откройте адрес, указанный Vite (обычно `http://localhost:5173`). В отличие от прошлой HTML-версии, эту страницу нужно запускать через Vite.

Сборка и локальный просмотр собранной версии:

```sh
npm run build
npm run preview
```

## Структура

- `index.html`, `src/main.jsx` — HTML-обёртка и точка входа React.
- `src/App.jsx` — состояние страницы и обработчики. Пять отдельных `useState`: `currentMonth`, `currentYear`, `selectedDay`, `selectedTime`, `slots`.
- `src/components/` — шапка, подвал, индикатор этапов, календарь, его заголовок и сетка, слоты и нижняя панель. Один компонент — один файл.
- `src/data/date.js` — чистые функции календаря, сравнения и форматирования дат.
- `src/data/slots.js` — те же демонстрационные интервалы, что в задании 2.
- `src/index.css`, `src/styles.css` — базовые стили и оформление страницы.
- `vite.config.js`, `package.json`, `package-lock.json` — конфигурация и зависимости.

Вместо `innerHTML` используется JSX с `.map()` и стабильными `key`. События задаются через `onClick`, данные передаются через props. Нет глобального изменяемого состояния и ручных подписок на события DOM.

## Проверка поведения

1. Откройте страницу: сегодняшний день выделен, его слоты уже показаны. Дни до сегодняшнего отключены. Выберите свободное время — оно появится в нижней панели, «Далее» станет доступна.
2. Выберите другой день: слоты обновятся, время сбросится, «Далее» снова отключится. Занятые слоты недоступны.
3. Полистайте месяцы, включая декабрь/январь: заголовок и сетка обновляются. Выбор дней и времени работает после переключений. Проверьте страницу на узком экране.

Нижняя панель показывает день недели, число, месяц, год и выбранное время. Как и в задании 2, «Далее» выводит выбранные данные в диалоге. Других страниц в исходном макете нет.
