# НЕБО — страница выбора даты и времени

Учебная вёрстка одного экрана онлайн-записи в студию красоты «НЕБО».

## Как открыть

1. Откройте `index.html` в браузере.
2. Либо откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server.

## Файлы

- `index.html` — семантическая HTML-разметка страницы.
- `styles.css` — оформление, состояния наведения, выбор даты и времени, адаптация для мобильных экранов.
- `images/` — папка для изображений, если они понадобятся.

Выбор даты и времени оформлен с помощью HTML radio inputs и CSS. Кнопки навигации показаны как элементы макета и пока не переводят на другие страницы.
